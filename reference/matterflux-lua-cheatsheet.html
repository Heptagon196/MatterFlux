Lua 内容接口速查表

Schema 1 · Lua 5.4 · 游戏线程 · 事务式提交

API用途
set_manifest(id, revision, schema)每个文件恰好调用一次；当前 schema 为 1。
register_material(id, density, hardness, r, g, b, a)注册模拟/显示材质定义。
register_decorator(id, generator, material, weight, min, max[, collision])选择 C++ 生成策略并配置材质、数量和碰撞；省略碰撞时为 false。
register_entity(id, behavior, health, speed)注册敌人或可动物体的静态定义。

当前生成策略

  • tree：森林树木生成规则；碰撞配置只作用于树干，树冠无碰撞。
  • surface_scatter：草、花等表面散布规则；默认无碰撞。

ID 规则

1–64 个字符，只允许字母、数字、下划线、短横线、点和冒号。推荐层级命名，例如 forest.flower.pink。

不可用能力

os、io、package、debug、 dofile、loadfile、load、 collectgarbage、math.random。
